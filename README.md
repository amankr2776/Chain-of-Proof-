## 🔮 QpiAI Quantum Ecosystem Integration

Our platform leverages the full power of the **QpiAI Cloud** to provide deterministic optimization and cryptographic security.

### 🧬 QpiAI Opt SDK (QUBO Optimization)
We utilize the `qpiai-opt` SDK to solve complex binary optimization problems (QUBO) that determine the fate of retired batteries. This is processed via our **FastAPI Backend** running on high-performance compute nodes.
*   **Disposition Strategy**: Dynamically allocates retired packs between **Second-Life (BESS)** and **Direct Recycling** to maximize residual value and minimize carbon footprint.
*   **Scale Testing**: Proven linear scalability from 6-unit pilot to **100+ unit enterprise fleet** disposition in under 200ms.

### 🌌 QpiAI QCloud (Quantum Hardware)
Every sensitive event (SOH update, Ownership Transfer, Recovery Claim) is sealed with a **128-bit Quantum Random Number (QRNG)** generated on real quantum hardware via the `qpiai-quantum` SDK:
*   **Hadamard Superposition**: QRNG seeds are generated by measuring qubits in the Hadamard state, ensuring true non-deterministic entropy.
*   **L2 Ledger Security**: Protects the hash-chained ledger against pre-image attacks and provides an unforgeable "Quantum Seal" for regulatory compliance.

### 🌐 QpiAI API & SDK Connectivity
*   **Backend Stack**: Python 3.10+ FastAPI Microservice (`main.py`).
*   **SDKs**: `qpiai-opt` for MILP/QUBO, `qpiai-quantum` for QRNG.
*   **Cloud Tunnel**: Secured via Cloudflare at: `https://wto-bruce-rate-creating.trycloudflare.com`

## 👥 Persona-Driven Workflow

The platform implements strict **Role-Based Access Control (RBAC)** to ensure data integrity across the value chain:

1.  **Manufacturer (OEM)**: Mints initial passports, manages Genesis SOH baseline, and signs material composition data.
2.  **Second-Life Operator**: Manages batteries in grid storage, monitors real-time degradation, and runs QUBO disposition solvers.
3.  **Recycler (Refiner)**: Manages hydrometallurgical recovery, submits mass-balance claims, and anchors recovery proofs on the L2 chain.
